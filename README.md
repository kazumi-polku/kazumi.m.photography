# Kazumi.M photography

GitHub Pages 公開用のサイト一式です。

## GitHubへのアップロード

このフォルダの中にある以下の項目を、リポジトリの一番上（ルート）へアップロードしてください。

- `index.html`
- `style.css`
- `assets` フォルダ
- `README.md`

ZIPファイル自体や、このフォルダごとではなく、**中身をアップロード**します。

## GitHub Pagesの設定

1. リポジトリ上部の「設定」を開く
2. 左側の「Pages」を開く
3. Sourceで「Deploy from a branch」を選ぶ
4. Branchを「main」、フォルダを「/(root)」にする
5. 「Save」を押す

数分後にサイトが公開されます。
